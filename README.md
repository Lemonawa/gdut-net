# gdut-net

[![CI](https://github.com/Lemonawa/gdut-net/actions/workflows/ci.yml/badge.svg)](https://github.com/Lemonawa/gdut-net/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/Lemonawa/gdut-net)](https://github.com/Lemonawa/gdut-net/releases)
[WTFPL](./LICENSE)

Third-party wired-network auth client for Guangdong University of Technology (Higher Education Mega Center campus): a single Rust binary running as a Windows service that dials and keeps a PPPoE session alive, auto-redials on drops, with an optional Dr.COM heartbeat compat mode. Coexists with Clash TUN / Tailscale (wintun) — all dial and probe traffic is explicitly bound to the physical NIC.

Replaces the official Dr.COM client. No LSP/npf injection.

## Install (admin PowerShell)

```powershell
# after downloading or building gdut-net.exe:
.\gdut-net.exe install          # prompts for campus password (or --password-stdin for scripts)
net start gdut-net
```

`install` does:

1. Verify admin rights (fails fast otherwise)
2. Prompt for the campus password (DPAPI-encrypted into config, never plaintext on disk); reuses the student ID if a config already exists
3. Create the PPPoE phone-book entry `gdut` (`C:\ProgramData\gdut-net\gdut.pbk`)
4. Register the Windows service `gdut-net` (auto-start; restart on failure 5s/30s/60s, 24h reset)
5. Register an event-log source (for `log.event_log = true`, mirrors warn/error into Event Viewer)

Once started, the service dials automatically; drops are redialed with exponential backoff (starts at 1s, caps at 5 min; auth failure 691 fixed at 10 min). If redial keeps failing for ≥10 minutes, a system toast pops.

## Uninstall

```powershell
.\gdut-net.exe uninstall            # stops and removes service, event source, entropy key
.\gdut-net.exe uninstall --purge    # also removes C:\ProgramData\gdut-net (config + logs)
```

Every step is idempotent — safe to re-run; `--purge` guards the directory name (only deletes a directory literally named `gdut-net`).

## Configuration

`C:\ProgramData\gdut-net\config.toml` (TOML, generated by install):

```toml
# HEMC (Higher Education Mega Center) auth server 10.0.3.2; Longdong / Dongfeng Road use 10.0.3.6
# Heartbeat is disabled by default; capture packets before enabling (see docs/adr/0002)

[account]
student_id = "your student id"
password_blob = "…DPAPI ciphertext (written by install; do not edit)"

[dial]
entry_name = "gdut"                      # dial entry name
pbk_path = "C:\\ProgramData\\gdut-net\\gdut.pbk"
interface = ""                           # physical NIC friendly name; empty = auto
probe_interval_secs = 30                 # probe interval (min 5)
http_probe_url = "http://223.5.5.5"      # HTTP fallback probe

[heartbeat]
enabled = false                          # compat mode switch (default off)
module = "gdut"                          # only "gdut" is supported
server = "10.0.3.2"                      # HEMC; Longdong/Dongfeng Road 10.0.3.6
port = 61440
interval_secs = 20

[log]
dir = "C:\\ProgramData\\gdut-net\\logs"
max_size_mb = 5                          # per-file rotation threshold
rotate_keep = 5                          # rotated files to keep
event_log = false                        # mirror warn/error to Windows event log
```

| Field | Meaning |
|---|---|
| `account.student_id` | Student ID (auth username) |
| `account.password_blob` | DPAPI-encrypted password (machine scope; written by install, do not hand-edit) |
| `dial.entry_name` / `dial.pbk_path` | RAS phone-book entry and path |
| `dial.interface` | Force a specific physical NIC; set it when multiple NICs or auto-detect picks wrong |
| `dial.probe_interval_secs` | Drop-probe period |
| `dial.http_probe_url` | HTTP fallback probe when gateway ICMP fails (tells "kicked" from "link down") |
| `heartbeat.*` | Dr.COM heartbeat compat mode (default off, see below) |
| `log.*` | Log dir, size-based rotation, retention, event-log mirror |

### Heartbeat compat mode (default off)

If the server enforces heartbeat validation, directly-dialed sessions get kicked periodically; enable `heartbeat.enabled = true` (sends Dr.COM keepalives, UDP 61440, one round every 20s).

**Risk note**: the heartbeat constants (server IP, flags, seed checksum) are decades old, and the GDUT variant differs from the drcom-generic P build — **capture packets on campus before enabling** (Wireshark filter `udp.port == 61440`, compare against the official client), see [ADR-0002](docs/adr/0002-heartbeat-gdut-variant.md).

If the official client occupies local UDP 61440, compat mode is unavailable and the service logs an error (retries after 60s, never silently).


## Development

```bash
cargo test                                  # pure-logic unit tests (runs on Linux)
cargo clippy -- -D warnings
cargo fmt --check
cargo check --target x86_64-pc-windows-msvc # verify Windows-only code from a Linux dev box
cargo build --release                       # produces gdut-net.exe (on Windows)
```

CI (`.github/workflows/ci.yml`): `linux-test` (test + clippy + fmt), `windows-build` (test + clippy + release build + `gdut-net-x86_64.zip` artifact), triggered on push to main and all PRs. Pushing a tag `v*` runs [.github/workflows/release.yml](.github/workflows/release.yml), which builds and attaches `gdut-net-x86_64.zip` to a GitHub Release automatically.

Architecture and domain vocabulary: [CONTEXT.md](CONTEXT.md); design decisions: [docs/adr/](docs/adr/) (heartbeat variant tradeoff ADR-0002, two-stage drop detection ADR-0003, service/tray split ADR-0001, tray icon choices ADR-0004). Personal deployment kit (one-click home/campus switching, proxy rules): [docs/desktop-kit.md](docs/desktop-kit.md).
