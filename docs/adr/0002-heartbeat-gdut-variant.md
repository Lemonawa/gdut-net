# 心跳兼容模式采用无登录态 GDUT 变体

GDUT 心跳与认证是分离的：该变体不需要 challenge/salt/login 登录态，用 8 字节探测包直接从服务器拿 seed/host_ip，四个 UDP 报文（ka1 探测、ka1 96B、ka2 type1、ka2 type3）打 `服务器:61440`（本地也 bind 61440），20 秒一轮。依赖登录 salt 的 P 版全流程在"无登录态守护进程"里走不通，已否决。Rust 实现按本项目独立整理的协议规格（常量表 + 报文偏移）编写。

心跳默认关闭；服务器 IP（大学城 10.0.3.2）、keep_alive1_flag（既有资料中 2a/6a 两说并存）等常量年代久远，启用兼容模式前必须在校园网内实测验证。
